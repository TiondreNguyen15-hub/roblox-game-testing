ORGANIZED WORKSPACE UPDATE

1. Leave your working demo open. Extract ALL files from this ZIP.
2. Run Update-Game-ESP.cmd. GPU libraries, existing models and saved settings are preserved.
3. The app opens on Home. Follow Capture > Detection > Tracking.

Detection is the former Game ESP page. Tuning/saving, overlay, diagnostics and recorded OCR are grouped in sections.
Tracking uses X / horizontal, Y / vertical and FOV overlay tabs. F9 disarms. F8 only controls overlay visibility.
System > Compute checks holds the existing validation and benchmark controls. Data lab holds local JSON/simulated visuals.
Click Expand layout if your previous saved window size is compact. Model paths and arming behavior are unchanged.

For a CPU-only runtime, the optional Update-And-Enable-GPU.cmd repairs GPU dependencies and updates that exact app. Installation alone is not proof of GPU execution.
Trained ONNX weights remain separate. See payload/GAME-ESP-README.md and payload/TRACKING.md.
If startup fails, send launch-failure.txt from beside the installed executable.
