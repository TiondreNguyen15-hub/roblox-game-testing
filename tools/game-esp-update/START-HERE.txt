HOLD ACTIVATION FIX

1. Leave your current demo open, Extract ALL files, then run Update-Game-ESP.cmd.
   Models, GPU files and saved settings are preserved.
2. Tracking: choose Activation mode > Hold selected key and choose your key/button.
3. Click START LOCK. The selected mode and key now stay unchanged.
4. Switch to the selected game and hold the key to activate. Release it to stop.
   Hold does not auto-activate just because the game gets focus.
5. Save tracking setup to persist your selected mode/key. Active/armed state is never saved.

Toggle still works when explicitly selected. Its START handoff waits up to 10 seconds for game focus.
STOP / DISARM or F9 stops either mode. Lost focus cancels an active toggle.
Previous versions forced Toggle when START LOCK was clicked; choose Hold again after updating if that old selection was saved.
Stable boxes, Fast lock preset, model/capture/GPU settings and the DX11 renderer remain.
Actual Apex acceptance/model accuracy/hardware performance still require PC testing.
If startup fails, send launch-failure.txt beside the installed executable.
