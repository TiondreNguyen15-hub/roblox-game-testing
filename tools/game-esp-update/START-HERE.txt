TRACKING ACTIVATION UPDATE

1. Leave the current demo open. Extract ALL files, then run Update-Game-ESP.cmd.
   Existing GPU files, models and saved settings are preserved.
2. OBS must show the actual game first. Desktop pixels cannot supply game targets.
   See GAME-ESP-README.md: OBS desktop troubleshooting.
3. Connect live Capture, load the Apex model in Detection and verify real boxes.
4. Tracking: select the Apex game, then click START LOCK.
5. Switch to that game within 10 seconds. A fresh detected character inside the circle is required.
   START LOCK uses Toggle mode. Losing focus cancels its active toggle.
6. STOP / DISARM or F9 stops input. The configured activation key toggles it off in-game.

Alternative: choose Activation key / button and Hold or Toggle mode, enable tracking, then use that key in-game.
Responsive follow preset is optional; game sensitivity still needs calibration.
Save tracking setup saves preferences, never active/armed/window state.
Screen overlay > Show on screen displays the circle/status on the selected monitor. F8 hides/shows graphics only.
Actual Apex response, capture configuration and private-model GPU performance require PC testing.
If startup fails, send launch-failure.txt beside the installed executable.
