TRACKING UPDATE

For a copy with working GPU files: leave the demo open, Extract All, then run Update-Game-ESP.cmd.
If that copy still has a CPU-only ONNX runtime: use Update-And-Enable-GPU.cmd instead. If the app is closed, select its installed EXE when prompted. Pinned GPU packages may download; cached files are reused.

Capture Apex Firing Range in OBS, start Virtual Camera and the app receiver. Enable the existing Apex model on Game ESP.
Open Tracking > Refresh Apex windows > select the game. Configure X / Y and enable the FOV circle.
Arm explicitly, focus the selected game and HOLD RIGHT MOUSE. Release to stop. F9 globally disarms. F8 only hides/shows graphics.
Arming and target window are not restored from settings. Windows accepting input does not prove Apex uses it.

Keep your private ONNX files; they are not included. See payload/TRACKING.md and GAME-ESP-README.md for setup and limits.
If startup fails: send launch-failure.txt from beside the installed executable.
