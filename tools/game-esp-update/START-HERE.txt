SCREEN OVERLAY UPDATE

1. Leave your working demo open. Extract ALL files from this ZIP.
2. Run Update-Game-ESP.cmd. It preserves your GPU files, models and settings.
3. Open Screen overlay in the left sidebar.
4. Click Show on screen and select the monitor where you play.
5. The SCREEN OVERLAY ON badge and configured FOV circle appear on the actual desktop immediately.

Use borderless/windowed game mode. Exclusive fullscreen may cover desktop overlays.
F8 hides/shows graphics. Show on screen also clears the F8-hidden state.
Actual boxes require connected live OBS capture, a loaded model and fresh accepted detections.
Draw detected boxes and Draw FOV circle are independent. Recordings remain inside the preview.
F9 disarms tracking. Enabling the overlay does not arm mouse following.

For GPU dependencies only, optional Update-And-Enable-GPU.cmd repairs them and updates that exact app.
Installation does not verify GPU execution. Trained model weights remain separate.
If startup fails, send launch-failure.txt beside the installed executable.
