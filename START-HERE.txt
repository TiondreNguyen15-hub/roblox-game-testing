BLOCKLINE — INTRO, MENU AND MINIMALIST ARENA

DOWNLOAD AND OPEN
Download the GitHub repository as a ZIP, extract it, then use Roblox Studio:
File > Open from File > Blockline.rbxlx. Press Play.

Blockline.rbxlx = full intro/menu and real arena/practice modes.
Arena-Phase1.rbxlx = map only, default Roblox movement, no gameplay scripts.
BlocklineArena.rbxmx = map-only model to insert into an existing Workspace.

Files display as XML when opened in a browser. They must be opened in Studio.
Download a fresh copy to receive GitHub updates.

PERSISTENCE
Publish a test experience. For Studio saving tests, enable Game Settings >
Security > Enable Studio Access to API Services. Settings, progress, credits,
weapons and rewards use DataStoreService. If cloud storage is unavailable,
the menu explicitly reports session-only data and blocks cloud purchases and
daily rewards. It will not overwrite an existing cloud profile with fallback data.

PC: WASD move, Space jump, click fire, right click aim, R reload, Shift run,
M or MENU opens the menu. Controller and touch actions are included.

Studio movement/physics, actual cloud storage and real devices still need
live testing. See README.md and STUDIO-TESTS.md for setup and validation.
