BLOCKLINE — FULL PROTOTYPE

Extract Blockline-Full.zip. In Roblox Studio choose:
File > Open from File > Blockline.rbxlx, then Play.

Use MODE on the PLAY page to select TDM, FFA, Duel or Practice.
Competitive modes require two players. Use Studio Server & Clients testing.
On the PRACTICE page choose Stationary, Moving, Tracking, Flick or Reaction.

WASD move, Space jump, mouse look, click fire, right-click aim, R reload,
Shift sprint, C/Ctrl crouch, 1/2/3 weapon, M menu. Touch and controller
bindings are included; see README.md.

Publish a test experience and enable Studio API access for persistence tests.
Cloud failures are clearly reported; fallback data never overwrites cloud data.

Source: Server.luau, Client.luau, Movement.luau.
Map-only: Arena-Phase1.rbxlx and BlocklineArena.rbxmx.

Read FEATURES-AND-ISSUES.md before release. Automated headless checks passed,
but actual Roblox Studio physics/rendering, live multiplayer/storage,
physical console/mobile devices and 60+ FPS still require validation.
